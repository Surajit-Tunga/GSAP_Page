# GSAP Page

This project is a visually engaging web page created as a learning exercise following a tutorial by JS Mastery. It demonstrates how to build modern, animated interfaces with smooth transitions and stylish layouts.

## Tech Stack

- **React** – For building the user interface and managing component state.
- **Tailwind CSS** – For fast, utility-first styling.
- **GSAP (GreenSock Animation Platform)** – For advanced animations and smooth motion effects.

## Features

- Responsive, modern UI built with React and Tailwind CSS.
- Smooth and interactive animations powered by GSAP.
- Clean, modular code structure for easy customization.
- Optimized for both desktop and mobile experiences.
